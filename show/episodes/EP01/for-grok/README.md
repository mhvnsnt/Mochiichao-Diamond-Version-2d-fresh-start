# For Grok — EP01 generation package

This folder is the complete EP01 generation package: the shooting script,
the beat sheet, the cue sheet, the per-scene breakdown for every scene, the
character roster with canon references and rulings, the plates list, and the
full style library — everything needed to generate episode 1's scenes.

It was assembled on 2026-10-28 as a self-contained hand-off bundle for
outside generation (Grok).

The main package document is `EP01-GENERATION-PACKAGE.md` in this folder.
The canonical package document also lives in the repo at
`show/episodes/EP01/GENERATION-PACKAGE.md`.

This folder is a snapshot copy dated 2026-10-28.

## Gap-fill update (2026-10-28)

The EP01 gap-fill programme has closed the fillable gaps named in §11 of
the generation package. Start with `GAP-FILL-REPORT.md` in this folder —
the full record: what was done per gap, the canon source each fill rests
on, its status (FILLED / CANDIDATE / DERIVED / OWNER-OWED), and what the
programme does not claim.

- `EP01-GENERATION-PACKAGE.md` in this folder is the updated package:
  every §11 gap item now carries a dated GAP-FILL resolution line.
- `gap-fill/` mirrors the new/changed production files from the gap-fill
  PRs (#26–#33) at their repo paths, so this bundle is self-contained for
  outside generation: the Gate / Pond / Green / Berry Store plates (with
  grade scripts and provenance), the EP01 props and their registry, the
  human reference packs (Mochiko / Hex / Aeon), the creature candidate
  sheets + records + updated pack files, the plates registry, the parts
  catalog, and the clip index.
- The staging file in this folder (`EP01-V3-staging.json`) already
  carries the PR #27 eye-whites correction and is byte-identical to the
  repo's staging file on main.

Candidate sheets are CANDIDATE, not canon — the owner locks sheets only
after seeing them. Derived plates are registered CURRENT-FOR-EP01 for
this episode's use; the Pond and Green canon plate gaps remain open.
