# Working method — the construction-kit rule

**This project's standing rule for using source material.** It is
Jamar's fixed working method for this project and for his show/game
projects generally. It governs how all donor material is classified
and handled here (see the TRANSFER-MANIFEST and the show production
indexes, which apply this rule).

## The rule

Source productions are used **only as donors of the construction
kit** — the stuff a production is *built from*:

- tools and editors
- pipelines and workflow systems
- resources and materials the tools use (palettes and color systems,
  textures, mouth-chart and expression systems, pose libraries,
  timing/exposure references, brush/ink settings)
- environments, background pieces, props and items
- rig systems, rig specs and conventions
- conventions, templates, and underlying systems / code patterns

**What never comes over:** source characters, character names, and
logos/branding. Not in episodes, not in the game, not in marketing.

**Identity-bearing pieces are rebuilt, not carried.** Anything in a
source that is proprietary or specific to one of its characters — a
character's own mouth pack, eyes, hands, body pieces, a character
rig, an episode's animatic — is **replaced with original material**:
the system behind the piece is rebuilt natively for this cast, in
this project's own art and proportions. The piece itself never
crosses over as itself.

## Reuse-first

We already have most of the pieces and parts. The working order is
always:

1. **Catalogue** what exists (indexes, parts catalog).
2. **Select** what fits, applying the filter above.
3. **Assemble** from existing parts.
4. Create new assets only for what is genuinely missing.

## How to classify something new (the 10-second test)

1. Is it a character, a character's name, or a logo/brand mark?
   → **Out.** No exceptions.
2. Is it a piece *of* a specific character (their mouth/eyes/hands/
   rig/animatic)? → **Rebuild natively** from the system; the piece
   stays where it is.
3. Is it construction kit (tool, pipeline, material, environment,
   prop, system, convention, code pattern)? → **Eligible** —
   catalogue it, convert it to this project's native form where it
   carries source styling, and use it.
4. Still unsure? → Default to rebuild/pointer and flag it in the
   relevant index rather than guessing.
