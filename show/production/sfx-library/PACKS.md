# SFX seed packs — provenance (pull-in programme, 2026-10-28)

Both packs by **Kenney Vleugels (kenney.nl)**, licence **CC0**
(open / public domain) for every file. Verification at source,
2026-10-28: (1) kenney.nl pack page License field reads
"Creative Commons CC0" and Kenney's support statement says all
asset-page assets are CC0, commercial use allowed, no attribution;
(2) each OpenGameArt page's license-name field reads "CC0";
(3) the `License.txt` inside each staged pack states CC0
(copies staged beside the loose audio).

Download channel note: kenney.nl serves pack zips through a
signed, expiring download link that cannot be fetched from this
VM's tooling (403 on the signed URL), so the packs were pulled
from **Kenney's own OpenGameArt uploads** — the author's official
mirror of the same packs.
