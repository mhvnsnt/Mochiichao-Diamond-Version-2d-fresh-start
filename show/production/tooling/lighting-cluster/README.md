# Lighting cluster — the NVIDIA-adjacent production-software pull-in

Start at **CLUSTER-MAP.md**: every member of the cluster (NVIDIA
Omniverse + the open stack it is built from), its verified licence
bucket, its teardown, and its wiring status.

- `OMNIVERSE-TEARDOWN.md` — the prime suspect, torn down + the
  rebuild-the-function map onto open pieces.
- `OPENUSD-TEARDOWN.md` + `usd/` — the Garden Gate lighting keys as
  real USD data, with a validator (64/64 at landing).
- `MATERIALX-TEARDOWN.md` + `materialx/` — the lustre law (LV-1..LV-6)
  as a MaterialX look, with a checker (13/13 at landing).
- `OPENCOLORIO-TEARDOWN.md` + `ocio/` — the house OCIO config for the
  Natron composite stage, with a checker (16/16 at landing).
- `GAFFER-TEARDOWN.md` — verdict: reference architecture, optional
  entry, not installed.
- `RTX-TECHNIQUES-NOTE.md` — the RTX algorithms mapped to house 2D
  analogues; no fake implementations.
- `TEST-RECORD.md` — the verbatim validation output for all three
  wired artefacts.

House rules these serve live in `show/bible/LIGHTING-SYSTEM.md` and
`show/bible/COLOR-SYSTEM.md`; nothing here changes a rule — it gives
the rules standard data formats.
