# Wielder constitution highlights

Wielder is the in-repo production agent system. Its seats are
advisory only: a model's text can be recorded on a run but can never
change an outcome, unblock a park, or issue a pass. The finish-gate
verifier is the only pass issuer, and it is not a model at all.

Retrieval is capped at three chunks by default, the
retrieval_top_k setting, as a lost-in-the-middle countermeasure.
Critic output may never use pass language or praise.
