# Kaggle free seat budget

The Kaggle free tier gives roughly thirty GPU hours per week on
Tesla T4 cards with sixteen gigabytes of memory each. A session can
run two notebooks at once at most, and a session is recycled after
about twelve hours. Sessions are fuel: everything valuable is saved
out to the warehouse before a session ends.

The weekly quota is shared with the show pipeline, and show work
takes priority over experiments when the budget runs low.
