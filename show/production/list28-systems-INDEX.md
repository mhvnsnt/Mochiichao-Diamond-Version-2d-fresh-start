# LIST 28 TEARDOWNS (items 267–276) — package index

**This list is OWNER-DIRECTED (Jamar, 2026-10-27),
not programme-drafted.** The owner ruled four things
and this package builds exactly them: (1) a released
Mochi returns to the wild as the same individual,
catchable again by its old Ranger or a different
one; (2) stealing another Ranger's Mochi — the
mechanic the reference games only allow through
cheat devices, with Colosseum's snag as the
in-fiction version — is a real system; (3) a
personal **morale** scale pulled 100% from Red Dead
Redemption 2's Honor, and **reputation** pulled
100% from Fallout: New Vegas (fame and infamy as
separate tracks per group), wired together on (4)
a ladder of about 25 steps a side — **fifty in
total**. He then confirmed the whole list wires
**100% into both lanes** — game and show — and
named the long game it serves: a later generation's
thief anti-hero lead whose arc runs on this engine
(#276). The deep documentation for every pulled-in
mechanic — RDR2 Honor, FNV reputation, the snag and
cheat-device line, the mod community's working
theft systems — is the parallel research pass:
**RESEARCH-SOURCES.md, in this folder.** These
specs cite it as their source layer throughout.

Built under the same laws as Lists 25–27: plain
language; mechanics filled from the owner's canon,
then from the bases he directed (Pokémon, RDR2,
FNV); OPEN reserved for story/canon facts. And
under the REAL-CODE WIRING LAW: every cross-
reference was checked against the earlier packages'
own files before being cited (#106's location field
and tombstone, #211's refusal, #38's capture model,
#201's reputation classes, #230's discipline ladder,
#31's item registry, #99's Syndicate tiers, #180's
declared-row law, #210's stakes law — all read at
this build). Where a target could not be verified,
STAGING registers an **UNVERIFIED TARGET**.

**Two earlier packages are changed by this one,
and the package says so on its face:** #106/#211's
release model is **revised** (#267 — release is a
state change to wild; the tombstone's "never enough
to resurrect" and #211's "impossible by
construction" are revoked for the game lane), and
#201's reputation model is **superseded** (#270 —
its classes become a view over the 50-step ladder).
STAGING carries the exact revision steps; the
changes land in those files, not as contradictions
left standing between packages.
