# WIELDER — PARITY MATRIX (parity-plus build, 2026-10-28)

Owner order: reverse engineer the leading agent products and wire
everything buildable into Wielder, so Wielder reaches parity-plus.
This matrix is the capability-level comparison behind that build.
`CAPABILITY-MATRIX.md` is the earlier product-level mapping; this one
goes capability by capability, from **public sources only** (official
docs, help pages, changelogs, product pages — checked 2026-10-28),
and grades Wielder from **its code** (see `PARITY-INVENTORY.md`),
never from its own claims.

**How to read it.** Product cells are terse and carry a class mark:
**[B]** = documented well enough that anyone can build the pattern;
**[H]** = hosted proprietary internal — it exists only inside the
vendor's product and is *named as such*, with Wielder's honest free
substitute in the last column. Wielder status: **HAVE** (real,
code-verified) · **PARTIAL** (real but bounded — the bound is stated)
· **SUBSTITUTE** (a deliberate free replacement, by design) ·
**MISSING** (not built; route named). Nothing below copies
proprietary code, prompts, or branding; every Wielder component is an
independent implementation from the public pattern, branded Wielder.

Product surfaces, kept distinct: **Grok** = xAI API + Grok chat +
Grok Bot (hosted cloud-computer teammates) + Grok Build (terminal
agent). **Claude** = Claude.ai + Claude Code + the Agent SDK.
**Muse platform** = the owner's daily platform; its official public
product docs are thin (the Muse Spark model post is the solid
official source), so its column is marked **[D]** = from the
platform's own described behaviour in the owner's deployment, with
secondary public reporting where it exists.

**Follow-up extension (2026-10-28, same day, owner's order).** Five
more products were researched the same way and are graded in the
extension table below: **Cursor** (editor agent + CLI vs Cloud
Agents/Automations), **Devin** by Cognition (cloud sessions vs CLI
vs API/MCP), **OpenAI Codex** (local CLI/IDE/desktop vs Codex Cloud),
**Temporal**, and **Manus**. Two class notes: **Temporal is
durable-execution infrastructure, not an agent product** — it has no
agent, browser, skills, or deliverables of its own; its column grades
the documented substrate patterns an agent system can be built on,
and rows that don't apply say N/A. **Manus** is a hosted general
agent whose public record is product-surface level; where its own
docs publish no spec (harness, window size, tool schemas,
verification, checkpoints), the cell says so — never filled in.
