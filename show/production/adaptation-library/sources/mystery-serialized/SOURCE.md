# SOURCE.md — Mystery + Serialized Storytelling cluster

Adaptation-source library, Mochiichao show. Method: browser search + page fetch only (no GitHub API). Structure extracted only — **no full transcripts saved**; the notes files paraphrase beats and name, in brief, the lines/elements flagged do-not-adapt. Short structural excerpts only where a beat's shape needed an example (e.g. a barked training cue, a one-word refusal pattern).

Construction-kit rule applies: only structure, mechanics, pacing and reference *shapes* are taken from these sources. All characters, names, logos/branding, iconic lines and specific images are replaced with Mochiichao-native material — see the do-not-adapt flag list in each notes file.
