# #200 — LUSTRE PRESENTATION (SHOW LANE) → cast, never rolled

**Seat in the doctrine:** show lane only. The game
layer owns lustre's definition outright: #15 (the
lustre presentation system — bundle format and
palette derivation) defines what a lustre individual
*looks like*, and #92 (lustre odds) defines how one
*occurs* in the game — by chance. This package
governs only how lustre appears in episodes, and
its first law is the lane split: **no odds are
rolled in the show lane, ever.** A die roll is not
a casting director, and an episode is not a random
encounter.

**What was studied.** Rare-variant presentation in
the publicly documented franchise record: in the
games, rarity is statistical; in broadcast, the
same rarity is editorial — the variant appears when
the story *casts* it, and its scarcity on screen is
a discipline of the production, not an output of
the game's odds table. The kit taken: casting as
the show-lane occurrence mechanism, with the game's
visual definition carried over unchanged so the
phenomenon is one phenomenon in both lanes.

## Native rules — lustre in episodes

- **A lustre appearance is cast.** The arc plan
  (#82) names the individual. A lustre character is
  an **individual** — a #80 record with its own
  seed, temperament, and history — never a palette
  swap performed on a species template for one
  episode's novelty. From the casting decision
  forward, that individual exists as a character;
  if the show needs a lustre Mochii, there is a
  specific Mochii, and the record says who.
- **Visual grammar is #15's, staged.** The episode
  renders lustre with the same palette derivation
  the game bundle uses, so a lustre individual is
  recognisably the same phenomenon on screen as in
  the game. The show invents **no** additional
  lustre grammar — no extra aura, sparkle, or
  effect vocabulary beyond #15's definition.
  Presentation that exceeds the definition would
  quietly make show-lustre a different thing from
  game-lustre, and the two-lane doctrine forbids
  the drift.
- **Conservation holds (#82 entry = exit).** A
  lustre appearance changes no canon state by
  itself. If a lustre individual **joins the
  recurring cast**, that is a canon act, recorded
  in the arc plan as one — casting a regular is an
  owner-level decision, not a default this package
  grants to any episode that wants one.
- **Rarity is kept by casting restraint.** The game
  makes lustre rare by odds (#92); the show mirrors
  the rarity by discipline — lustre appearances are
  rationed the way #82 rations dread: scarcity is
  the meaning, and frequency would spend it. This
  package asserts **no quota** (how often is an
  owner taste slot, below); it asserts the
  mechanism: every appearance is a recorded casting
  decision in the arc plan, auditable after the
  fact — so if lustre ever starts appearing
  casually, the record shows exactly when the
  discipline slipped.
- **The game lane is untouched.** Nothing here
  changes #92's odds, #15's derivation, or any
  individual record. A show casting creates no
  game-lane individual; the lanes join at the
  character level only through owner canon acts,
  per case.

## Wiring (proposed)

Lives with the show-lane packages beside #82.
Reads: #15 (definition), #82 (arc-plan casting
records), #80 (individual records). Writes: casting
decisions in arc plans only. No game-lane wiring
exists for this item, by design.

## Open slots (nothing invented)

Any actual lustre casting (**none exists**) · the
rationing taste — how rare is rare on screen
(owner's) · whether a show-first lustre character
ever receives a game-lane record (owner canon act,
per case, never automatic).
