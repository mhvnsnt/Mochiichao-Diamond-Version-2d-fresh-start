# Goddgachuu (#400) — Variant Grid — CORRECTED STRUCTURE (owner, 2026-10-28 ~18:00 CT)

This is a BUILD LIST, not a pick list: every cell gets made.
Doro's first draft flattened this into two batches — that was wrong. The real structure
is one matrix: FIVE VARIANTS, and EACH variant exists in ALL FIVE COLOURWAYS, with the
jewel colours running across them too.

Locked: the MAIN/DEFAULT version = concept 5 (white body, blue antlers, yellow lips,
sapphire-blue chest jewel, blue-and-gold sash, white fur, Japanese swirl-and-spike storm clouds).
Grid law (species colour system): palettes move freely; accent placement, the trait set,
the silhouette, and the eye colour family (yellow) never move.

## Axis 1 — the five variants (V1–V5)
Each variant is its own version of him, set apart by its jewel and sash treatment:
- V1 — jewel-swap variant: its own jewel colour, sash in the default style
- V2 — jewel-swap variant: its own jewel colour, sash in a different colour
- V3 — TWO-COLOUR SASH variant: sash carries two colours (a main + a secondary colourway colour), its own jewel
- V4 — jewel-swap variant: its own jewel colour, sash in another different colour
- V5 — jewel-swap variant: its own jewel colour, sash in another different colour

## Axis 2 — the five colourways — EVERY variant comes in ALL of them
- CW1 — the main colourway (concept 5's white-and-blue)
- CW2 — full different colourway #2
- CW3 — full different colourway #3
- CW4 — full different colourway #4
- CW5 — full different colourway #5
(Colourway palettes themselves are the owner's to set as each is made; candidate palettes
from Doro's draft — Tempest Black, Crimson Storm, Jade Heaven, Royal Violet, Golden Sun —
are starting suggestions for CW2–CW5, not decisions.)

## Axis 3 — jewel colours (5 to 10, running across the matrix)
Pool: Sapphire blue (default) · Ruby red · Emerald green · Amethyst purple · Topaz gold ·
Rose pink · Citrine orange · Onyx black · Opal white · Turquoise teal.
Each version can carry a different jewel colour from the pool.

## The build count
5 variants × 5 colourways = 25 core versions, × the jewel colours across them.
ALL of them get made — Goddgachuu has the most variations of any species.
Occurrence: each variant ~10% for now; percentages rebalance as more versions land.
The locked white-and-blue concept-5 version stays the default — the one encountered most.
