# #24 — OPENING-TITLE SEQUENCE STRUCTURE → show OP system spec

**Teardown (published TV-animation practice).** A creature-catcher
OP is a fixed grammar in ~90 seconds: (1) **hook image** (world +
promise, first 3 seconds), (2) **title card** on the musical downbeat
of the first chorus entry, (3) **cast parade** — principals in
signature motion, staged against the silhouette ladder so size and
importance read instantly, (4) **world tour** — the season's places
as living plates, (5) **rival/threat beat**, (6) **ensemble lockup**
— the group composition that becomes the season's key art, (7)
**button** — one quiet or comic held frame before the episode. OPs
are built as a BANK: shots are versioned per season and individual
shots are swapped (new species, new place) without rebuilding the
sequence — the same economics as the episode BANK system.

**Native spec — `mochiichao/op/v1`.**

- Slot map (90 s broadcast slot; EP01's full-length plan already
  budgets OP 60 s inside its 1,440 s accounting — the slot table
  carries both, 60 s marked as the current production target,
  90 s as the broadcast form; the discrepancy is the plan's, flagged
  here, not silently resolved):
  `OP-01 hook / OP-02 title card / OP-03 cast parade / OP-04 world
  tour / OP-05 rival beat / OP-06 lockup / OP-07 button`, each a
  banked shot id with duration, camera entry in #21's vocabulary,
  and a SCORE-STATE + stems reference (#13) so the OP mixes like
  any other scene.
- Cast parade roster = the **10 title creatures of canon** (the
  species with title videos in the repo): Mochii, Dorowani, Gabu,
  Kittember, Mythar, Razorgater, Sproutle, Tyrage, Wispkin,
  Yogiferno — parade order and per-creature signature motion are
  **OPEN** (owner/board), the slot structure is not.
- Title card: franchise identity kit (the design lane's identity
  work) — logo lockup, no per-episode variation; the card is a
  *held plate + sound event* (title sting in the stems manifest).
- Bank/version law: OP shots follow the current-version law —
  upgraded shots are marked CURRENT in the clip-index with the
  superseded named; a mid-season species swap edits one slot.
  Marketing cuts come from the OP bank + episode footage only
  (anti-slideshow law: never manufactured from stills).
- Production route: OP shots are avatar-full-stack bundles where
  generative, rig performances where puppeted — same gate as
  episodes (likeness gate, frame-verified animation only).
