## Landing notes for the side lane

- No existing repo file is modified by this package. The spawn
  instances *re-home* canon seed rows (values unchanged) — if the
  lane prefers migrating `encounters.json` into instances outright,
  that is a lane decision; the instances validate either way.
- `region1-route-graph.json` carries one flagged STRUCTURAL
  INFERENCE (Victory Route fragment threshold = 8). Land it with the
  flag intact.
- The wave-1 edges file is regenerable from
  `mochichao-design/COVERAGE-AND-ROADMAP.md` §4 by the parse used to
  build it; if the roadmap's line table changes, regenerate rather
  than hand-editing edges.
