# #71 — TUTORIAL FLOW GRAMMAR → onboarding format (game + show)

**Teardown (public documentation).** The well-documented teaching
grammar of the reference games and their successors, distilled from
design writing and decomp-visible script structure: **(1) Teach by
doing, in the world** — the first route is a curriculum: the first
wild encounter teaches the battle loop, the first Ranger battle
teaches reading an opponent, each new system arrives attached to the
place that needs it (the dojo/fragment cadence is a syllabus).
**(2) One verb at a time** — each beat introduces exactly one new
action and immediately gives a safe place to use it; nothing is
explained before it is needed. **(3) The guide is a character** —
instruction is diegetic (a professor/assistant figure, signs, a
device that demonstrates) rather than manual text; the Mochiioteca
handover is the genre's signature teaching scene. **(4) Failure is
cheap early** — early losses carry no spiral; the lesson is the
loss. **(5) The gate is a demonstration, not a quiz** — progress
unlocks when the player *does* the thing (keeps a partner, reads a
footprint), which the flag system can test. Kit taken: the five
moves. No scripts, text, or layouts are copied — our beats below are
built from Mochiichao canon (the season canon map's opening), not
from any game's script.

**Native format — onboarding beat sheet.** One format serves both
lanes; a beat is `{id, verb, teacher, place, safe_rep, gate_flag,
show_echo}`:

| # | Beat (game) | Verb | Teacher / place | Gate (doing, not quiz) |
|---|---|---|---|---|
| B1 | Arrival — truck, Sector 0 / Boot Harbor | move, look | world itself | reach the lab |
| B2 | The rescue — Aeon cornered by a wild creature | watch, then act | Aeon / lab approach | the rescue resolves |
| B3 | Partner + Mochiioteca handover | receive, open device | Aeon → the five starters (Mochii, Razorgater, Tyrage, Kittember, Sproutle) | partner chosen; device wakes (`story.*` flag) |
| B4 | Route Topaz (Route 1.0) — first wild meeting | meet (seen) | the route | first `seen` state (#14) |
| B5 | First keep + footprint reading | keep, read tracks | route / Garden threshold | first `kept`; footprint page wakes (#14 rule: kept-only) |
| B6 | The Garden opens (R1-BEAT3) | tend, release, call | **Assistant Mochiko** opens the Mochi Garden | garden systems unlock |
| B7 | First dojo approach | read a Ranger | road to dojo 1 | arrival (battle teaching scales per #70 bands) |

Every row is canon-sourced from the season canon map (game opening
wins; Hex is next-door neighbour and rival — his first appearance
slot in the beat sheet is **OPEN**, canon fixes who he is, not the
minute he enters). Text for every beat is unwritten — dialogue is
the dialogue kit's job; this format fixes *what is taught, where,
and what proves it*, never the lines.

**Show echo (why one format).** EP01's opening movement teaches the
*audience* with the same grammar: one verb at a time (the world, the
device, the footprint, the Forest's edge), a character as guide
(Mochiko), demonstration over exposition — and the show's subtitle
law is the tutorial law restated (words appear only at the moments
that must be *learned*). Episode beat sheets annotate `show_echo`
with the audience-verb each beat teaches; EP01 v2 already runs this
shape (its keeper framing anticipates B6) — the format names it so
EP02+ inherit it deliberately.

**Wiring.** Gates write #12 flags; state proofs read #14 states;
difficulty bands (#70 Dial A) key off the same progression. The beat
sheet lands beside the route graph (#11) — beats annotate graph
nodes rather than duplicating them.

**Coverage.** Grammar: standard, well documented. Contents: beat
*sequence* is canon (season canon map); all dialogue, Hex's entry
point, and any beat beyond B7 are OPEN.
