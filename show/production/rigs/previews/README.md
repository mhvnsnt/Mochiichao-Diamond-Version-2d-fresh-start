# Rig previews — idle renders of the committed TextRig rigs

Rendered 2026-10-27 with the TextRig renderer (headless,
Playwright/Chromium) from the committed DragonBones rig sets.
Each species has a full-loop idle GIF (30 fps) and a filmstrip
of the same loop.

These previews are renders OF the rig data — the rig data
itself (skeleton/texture/animations) lives in
`show/production/rigs/builds/<species>/` and is the source of
truth. If a rig is rebuilt, its preview here is superseded and
should be re-rendered.

Species: mochii, gabu, kittember, sproutle, dorowani, wispkin
(all six pilot species). Staged under the staging law
(2026-10-27) — previously local-only in the workspace
rig-previews folder; every file md5-verified on landing.
