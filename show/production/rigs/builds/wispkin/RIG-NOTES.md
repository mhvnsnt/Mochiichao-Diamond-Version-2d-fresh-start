# Wispkin — TextRig build v1 (2026-10-27)
First character rigged through the wired TextRig MCP (flat canon
cutout -> DragonBones). Whole-image DEFORM rig (the guide's
sanctioned choice for a fused-cluster character): 4 bones
(root/smoke/body/mask), 3 animations: float_idle (4s loop — body
bob, mask tilt = Wispkin's expression channel, smoke sway),
float_up (2.4s — the EP01 cut-23 float-up), mask_tilt_left (1.6s).
Source: canon title cutout (288x609). Build warning recorded:
85 mesh vertices on mask islands fell back to IDW weights —
acceptable for v1 (mask is a held prop by canon); revisit if the
mask deforms visibly at extremes. Files: wispkin_ske.json +
wispkin_tex.json + wispkin_tex.png (DragonBones runtime set for
Pixi). Likeness note: the rig deforms the CANON pixels themselves
— no redraw, no drift by construction.
