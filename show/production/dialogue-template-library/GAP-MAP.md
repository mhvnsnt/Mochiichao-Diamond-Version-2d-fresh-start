# GAP MAP — WHAT THE FABRIC STILL NEEDS, PER REGION

**Basis.** The spine is written (~70 beats, 5 region files + locked opening).
The fabric is ~10–20% written. Counts below are a *demand model* derived
from the canon skeleton (per region: 8 dojos, ~5 towns/cities, ~5 routes,
1 plateau ascent, 1 post-game area, gardens per the Garden canon) applied to
the TAXONOMY.md skeletons. They are production targets, not measurements of
repo files — region town counts for Regions 2–5 rest on the region files'
own beat lists, whose town names are partly provisional in canon.

**How the library changes the arithmetic.** Templates are multipliers, not
one-offs: one sign skeleton (P-07) writes every route sign in the game; one
clinic sequence (P-01) variants into every town. "Needed" below counts
*finished blocks to author*, with the pilot template that seeds each row.

## Blockers the fabric cannot fill (owner TBDs — Rule 8)
1. **Regions 2–5 dojo leaders are NAME GAP** throughout the dialogue files,
   and Region 2/3/5 champions likewise. F6 leader sets and champion texture
   wait on names; guides and underlings can be written *around* the gaps
   (P-20/P-21 pattern never names an unnamed leader).
2. **Region 2–5 town names are partly provisional** ("shape labels" in the
   source files). F3 signs and F4 barks for those regions should be written
   to the beat lists, with names slotted, not carved in.
3. **Gardens outside Region 1** are modelled, not canon-named — F7 counts
   for R2–5 are provisional.
4. **The Garden hub's display name** sits inside today's Secret-sweep
   territory ("Mainframe Gardens"); P-23 deliberately avoids naming the hub.
   One owner word settles every F7 header in the game.
5. **Region 3's festival form** and Region 4's transport form (airship is
   flag-canonical, dialogue-less) need one owner sentence each before F10/
   F11 production reaches them.
