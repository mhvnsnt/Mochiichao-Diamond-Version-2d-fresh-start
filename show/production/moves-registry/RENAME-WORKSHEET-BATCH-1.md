**Status:** Draft proposals only. **Nothing in this worksheet is locked, final, or applied to any game file.** Every drafted name below is a proposal for the owner (Jamar) to approve, change, or reject. Internal game ids / keys never change under this program — only display names would change, and only after owner approval.

**The rule (owner-set):** Any move name built from literal noun words or natural-disaster terms gets a Mochiichao display name that is the **coolest near-synonym** — meaning preserved, pretty much the same thing, said cooler. A player who knows the source move should recognise ours instantly. Names are one or two words, punchy and show-cool.

**Scope of this batch:** 40 source moves — the six B2/W2 Rare Moves (HM class), the machine moves already in our playable 36, and headline TMs.

**Machine class key:**
- **Rare** = HM-origin class (the Rare Moves)
- **General** = TM-origin class (the General Moves)

**Light-touch flag:** Where a source name is a single generic word with no good cooler synonym, the draft is a light-touch variant — kept near-identical on purpose so recognition is never lost. Those rows are marked **(light-touch)** in the Drafted Name column.
