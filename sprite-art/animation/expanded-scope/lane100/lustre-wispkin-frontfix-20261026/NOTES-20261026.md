## Front-base method (same revised rule, re-derived on cell_00)

cell_00 quantizes to a near-grayscale ramp, so mask vs body cannot split
by palette value alone (bright smoke wisps share the mask's white
entries). Region guard measured from the base: the mask face's bright
core is a 114px component at y 12-26, x 23-39, so the face bbox is rows
8-38, cols 16-48. Palette entries v >= 0.90 (entries 0, 1) count as MASK
only inside that bbox; the same entries outside it (lower smoke wisps)
take the body treatment. Mask may recolor per kind but stays bright;
body values lifted so colors show. Same 10 kind transforms, same
Showtime-brighten / Night-glow rim treatments as the revision builder.
