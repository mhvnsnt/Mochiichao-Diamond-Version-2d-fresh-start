Problem this spec solves: the five files have five different aspect
ratios. Placing them at equal file-pixel size would make Tyrage
(tall portrait) tower over Gabu (wide landscape) and break the
spec's "same scale" requirement. File size is NOT creature size.

## 1. Normalisation rule (the only rule that matters)

Scale each S1 image so the CREATURE's visible head-to-feet height
— not the file height, not the grass patch — is the same target
height in the composition. Measure that height at wiring time from
the creature's visible body in each file (top nub / head fin /
head fringe to feet), then scale the whole file by the same factor
for that creature. Do not crop, stretch, or re-pose any S1 file.

- Choice-row target: creature height = 38% of the composition
  height (see §2 for the two canvases). All three choice creatures
  share that target, so Mochii, Razorgater and Tyrage read as the
  same visual weight, matching the I2 trio frame.
- Showcase target (Dorowani / Gabu, when shown singly, e.g. a
  detail panel): creature height = 55% of the composition height.
  Never show the trio and a showcase creature at different
  normalised heights in the same frame.

## 2. Layout

### 2a. Choice screen (trio) — 1200 x 1500 portrait canvas (title canvas)

- Background layer: Title Backgrounds lane art, or T2
  title-bg-key-art-v2.png as the fallback. Creatures sit in the
  lower band only; the logo band (top third) stays empty.
- Ground line (shared): y = 1080 on the 1500 canvas. All three
  creatures' feet sit on this line — no floating, no staggered
  ground lines.
- Slot centres (x): Mochii 300, Razorgater 600, Tyrage 900.
  Order left-to-right is roster order (#001, #004, #007).
- Creature height: 570 px (38% of 1500) per §1.
- Descriptor window (UI layer, NOT baked into art): below the
  ground line, y = 1150–1420, full width minus margins. It carries
  the selected creature's name + descriptor (S2 wording, owed)
  and the selection cursor. No name/descriptor text is baked
  into any S1 image, and no new text is invented here.

### 2b. Choice screen — 1920 x 1080 landscape canvas

Same rules, scaled: ground line y = 760; slot centres x = 480,
960, 1440; creature height = 410 px (38% of 1080); descriptor
window y = 800–1020. If the game ships only one canvas, ship
the portrait (§2a) and centre-crop the landscape from it — do
not maintain two different compositions.

## 3. Selection state (UI layers, never baked into S1 art)

- Unselected creatures: full colour, no dimming baked in. Any
  dimming is a UI-layer opacity change at wiring time.
- Selected creature: UI-layer highlight ring / cursor only.
  No glow, outline, or shadow is painted into the S1 files.
- Shadows: SEPARATE engine layer (Mars correction 2026-10-25
  ~20:12 CDT — shadows are not part of character art). The
  grass patches already in the S1 files are ground detail, not
  shadows; the engine adds a shadow blob under each creature at
  wiring time. Do not bake a new shadow into S1 art to "ground"
  a creature.

## 4. Dorowani / Gabu — coordinator decision (not a new set)

TITLE-SEQUENCE-ART-SPEC.md §8 already warns: if the Title
Creatures lane delivers its own Dorowani/Gabu, the coordinator
picks ONE set for the selection/showcase screen — do not ship
both. This spec therefore gives Dorowani/Gabu no choice-row
slot. Their S1 files are showcase art (§1 showcase target)
until the coordinator picks the canonical set. No duplicate
Dorowani/Gabu art is generated by this spec.
