# Smear + anticipation spec (Step 1, attack + hurt) — NEW this pass
Source technique (public teaching articles, study-only, no text or art copied):
- Smear frames: an elongated/stretched in-between inserted between two key poses
  of a fast motion, so the eye reads a seamless fast move instead of a gap or a
  strobe. Rule from the teaching material: smears must be FAST — one frame,
  subconscious; if every frame is smeared the character just looks wrong-shaped.
  Use for: the strike limb / whole-body lunge on the travel frame only, never
  for idle or walk.
- Anticipation: a windup pose in the opposite direction before the strike.
  Teaching range for a readable windup: 0.3–0.6 s; harder opponents get a
  SHORTER windup, never a faster strike — the strike stays readable.
- Squash / stretch (volume preserved, same mass throughout):
  landing squash example scale ~(1.35, 0.7); jump/leap stretch ~(0.75, 1.3);
  origin at the feet so a squash lands INTO the ground instead of floating.
  Heavy body plans squash/stretch LESS and move with quicker timing; light
  body plans exaggerate MORE with slower timing.
Licence: technique only; the source articles carry no code or art staged here.
Wiring target: Step 1 agent — attack manifests (add one optional smear frame
slot on travel, windup duration per attack weight, squash/stretch scale pair
per body plan); Step 2 agent — battle timeline (windup event already exists,
smear frame sits inside travel, never inside the hit-stop freeze).
Gate: side-by-side with/without smear must show no screen-space gap between
the windup pose and the contact pose, and the rest-return error stays ~0.
Shadow rule: no baked shadow is added to any smear/anticipation frame;
shadows are a separate engine layer (see step4 separate-shadow-layer-spec).
