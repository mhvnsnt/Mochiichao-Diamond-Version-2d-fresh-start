# Y2K theme — logo + UI/menus (Mars, 2026-10-25)
Reference: Envato Tuts+ "20 Best Y2K Fonts" screenshot — Areion, Cyber Angel, Cytone.
NOT the dark-navy terminal look, NOT plain bold.

Logo rules:
- Bubbly, rounded, italic display letters, slightly arched/tilted
- Gradient fill: cyan -> blue (main), pink/yellow accents
- Thick white outline, chrome shine, drop shadow
- Stars + orbit ring around the wordmark
- Version word below in same italic style, pink outline
- Word: MOCHIICHAO, version: DIAMOND VERSION
- Fonts: open OFL lookalikes only (Bungee / Titan One / Fredoka style).
  Paid fonts in the screenshot (Cyber Angel $8.51 Etsy, etc.) are
  NOT bought or copied without Mars approval.

UI/menu rules (same theme):
- Panels: glossy, rounded 20px+, gradient (cyan/blue, pink/purple),
  white border, soft glow shadow — NOT flat dark navy, NOT mono
- Buttons: rounded, glossy, min 48px tap, italic bubbly label
- Headings: Y2K display font, italic, gradient
- Body: rounded sans, white / light grey on dark, never mono terminal
- Accents: stars, orbit rings, sparkles, chrome dividers
- HP bar: rounded, glossy gradient green/yellow/red (same thresholds)
- Dialogue box: bottom, full width, glossy rounded, portrait left,
  continue arrow — in Y2K panel style, not terminal frame
- Main menu windows: separate glossy Y2K panels, gold selected
  highlight, same FireRed sizes/positions as the replacement log
