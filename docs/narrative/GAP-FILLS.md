*Lane: narrative-flow. Every fill below is an ORIGINAL beat built
from Jamar's canon (names, places, species, systems verified in
the sources named per fill) and shaped by a flow rule from
GAME-FLOW-MAP.md / SHOW-FLOW-MAP.md. The rewrite test
(METHODS.md §2c) was applied to every fill as written; none of
these is a Pokémon plot with names swapped — each one's load-
bearing fact is a canon fact of his (the Reserve, the truth-buyers
line, the home clock, the keeper board, Rule 12) that has no
Pokémon counterpart. Owner slots are flagged in one line each,
and every fill is designed to work without its slot being filled.*

*Canon verified against: SEQUENCE-PLAN.md (staged bible-charge-
logging), region1-dialogue.json (R1-BEAT2…9 locked lines),
region1-truck-start.ink, SHOW-BIBLE.md, SEASON-CANON-MAP.md,
species data (Mochii 001, Razorgater 004, Tyrage 007, Kittember

"Mysterious Figure"; Castagnoli Island / "Luigi's Reserve" in game
