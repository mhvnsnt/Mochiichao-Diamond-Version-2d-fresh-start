# Pull-everything-then-swap rule (Mars, 2026-10-25 23:48 CDT, standing)

This is Mars's own rule. It supersedes any earlier assistant-imposed
do-not-pull / do-not-copy list. Do not make Mars repeat it.

## The rule, in order

1. **Pull everything in 100%.** Official files, Pokemon files,
   fan-made files, mod files, open source, anything you can pull
   in and wire up — pull it in. Do not narrow scope to avoid a
   proprietary-file question, and do not hand-tool a cheap version
   instead of pulling the real thing.
2. **Sift through it.** Identify the small amount of copyright /
   proprietary files in what was pulled in.
3. **Swap them out really fast.** Replace each proprietary file
   with a Mochiichao original in that exact spot — same structure,
   order, and slot, Mochiichao words, names, art, and canon —
   as soon as it is identified. Do not leave proprietary files
   sitting in the public repo, and do not stop the whole batch
   for one file that cannot be swapped cleanly: say so plainly
   for that one file and keep working on everything else.
4. **Ship the swapped, cleaned version.** The public repo gets
   the version after the swap, not the proprietary files.

## What this rule does NOT do

- It does not make a proprietary-file concern a reason to stall,
  lecture Mars, or ask him to repeat the rule.
- It does not invent a do-not-pull list Mars did not make.
- It does not change the anti-clobber laws in AGENTS.md: PR-only,
  0 file deletions unless a task says so, no force-push, no
  history rewrite, deletion check before every merge.
- It does not change the autonomous rule: keep working every
  10 minutes via mochiichao-autonomous-continue, surface only
  results, blockers, and Mars-only decisions shown first.
